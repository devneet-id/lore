# Rune

**Repo:** `devneet-id/rune` · **Package:** `devneet/rune` · **Language:** PHP · **License:** MIT

> A lore-driven, modular concept beneath PHP that responds to development rather than dictating it.

Rune is the foundation of the DEVNEET ecosystem — lightweight, lazy-loaded, process-based. No bootstrapping; each rune awakens only when invoked. Docs are live (Phantasm) instead of Reflection.

## This folder

- **[lore/](lore/)** — the story & teaching: the paradigm, the Acts, the vocabulary in context. _(rune-lore content migrates here.)_
- **[reference/](reference/)** — the technical detail: architecture, the ten origin runes, the CLI, lifecycle.

## At a glance

- **Triad:** Ether (truth) · Essence (flow) · Entity (behaviour), joined by **Manifest**, described by **Phantasm**.
- **CLI:** apps are a `cast` (a "runite"); commands are **casts**, options are **spells**.
- **Distribution:** seal a runite into a `.rune` **relic** (see [reliquary](../reliquary/)).

See [reference/](reference/) for depth and [../../glossary.md](../../glossary.md) for the vocabulary.
