# Projects

Depth, one folder per project. Each has two sides:

- **`lore/`** — the story & teaching (the narrative, Act by Act where it applies).
- **`reference/`** — the technical detail (architecture, APIs, commands, formats).

Cross-project material lives up a level: the map in [atlas/](../atlas/), the vocabulary in [glossary.md](../glossary.md). Status and history live in [chronicle/](../chronicle/).

## Index

- **[rune/](rune/)** — the lore-driven, modular foundation beneath PHP.
- **[reliquary/](reliquary/)** — the Federated Relic Registry for Rune.
- **[exura/](exura/)** — the minimalist framework series (exuraphp, exurajs, exuracss).

> Adding a project? Create `realms/<name>/` with `README.md`, `lore/`, and `reference/`, then link it here and in the root README.
