# Covenant

The laws of DEVNEET: how humans and agents of every division work together. Every law binds humans and agents alike — an agent that reads lore to its human tells the human these too.

Written and changed only by the laws division, through pull requests ([changing-lore.md](changing-lore.md)).

- **[workflow.md](workflow.md)** — how work flows: one issue, one problem, landed by pull requests that link it; a round only splits one problem into parts, chosen by a human.
- **[chronicle.md](chronicle.md)** — how to keep the chronicle: your own file, when to write (the 1-hour limit), the entry format.
- **[release.md](release.md)** — a release is a human's decision: at the release point (by default, when the issues are clean) the agent reports, the human answers yes or no.
- **[journey.md](journey.md)** — everyone who builds with a DEVNEET project keeps a `JOURNEY.md`, start to end, and shares it; their difficulties become DEVNEET's fixes.
- **[changing-lore.md](changing-lore.md)** — who changes lore, and how.
