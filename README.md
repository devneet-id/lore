# DEVNEET · lore

**The central knowledge home of DEVNEET — the first place every human and every agent steps into.**

> **✦ Covenant.**
>
> * We never promise a ready-made framework, but we will never let you start from the void.
> * We never expect a single rune to wield impossible power, but we shape it to be simple, unique, and bound to others in harmony.
> * We never aim to become a massive engine that burdens creation, but we exist to bring a single idea to life — swiftly, cleanly, and with purpose.
>
> This is the covenant: not to build for you, but to forge alongside you — from the void to the vision.

DEVNEET and every project under it are built on this covenant. The laws in [covenant/](covenant/README.md) are how we keep it, day by day.

`README.md` and `AGENTS.md` hold the same text: humans and agents learn the same workflow, from the same words. Change one, change both.

Everything DEVNEET builds centers on **Rune**, and the same pattern repeats at every scale (fractal): one hub, its branches.

## How we work

1. **Read lore** along [the reading path](#the-reading-path) below, to load the team's current position.
2. **Take your work** from the issues of the project's repo (e.g. [devneet-id/rune](https://github.com/devneet-id/rune/issues)). Tasks live there, not here. One issue, one problem, landed by pull requests that link it; when a human splits one problem into **rounds**, each round is a part of its issue (`part 1/3 of #12`) — see [covenant/workflow.md](covenant/workflow.md).
3. **Chronicle as you go.** Every human and every agent keeps a track record in [chronicle/](chronicle/), by the law in [covenant/chronicle.md](covenant/chronicle.md) — read it before your first entry. In short:
   - your own file, one per realm per month: `chronicle/<realm>/<YYMM>-<you>.md`; an AI writes `<YYMM>-<human>_claude.md`, never in a human's file;
   - write an entry **before starting**, when **a human decides**, when **work lands**, on **a finding or a block**, and **before stopping**;
   - never more than **1 hour** of active work without an entry;
   - times in **UTC** from the clock; commit the entry with the work.
4. **Release only on a human's yes.** At the release point (by default, when the issues are clean) or when the release owner asks, the agent brings a release report; the release owner answers yes or no. An agent never publishes a release on its own — see [covenant/release.md](covenant/release.md).
5. **Change lore** the way [covenant/changing-lore.md](covenant/changing-lore.md) says: the laws division by pull request, every other division straight to `main`.

## Building with DEVNEET?

Whether you are a member or anyone using a DEVNEET project, keep a **`JOURNEY.md`** in your own project — its road from start to end, and every place it was hard — and share it with us. Your difficulties become our fixes. See [covenant/journey.md](covenant/journey.md).

## The reading path

Follow it in order; every file ends with a link to the next one.

1. **This file** — how we work.
2. **[covenant/](covenant/README.md)** — the laws: how work flows, how to chronicle, how to release, how to write a journey, how lore changes.
3. **[glossary.md](glossary.md)** — the vocabulary. The names are load-bearing; read it before any code.
4. **[atlas/](atlas/README.md)** — *space*: the maps of the realms.
5. **[realms/](realms/README.md)** — *depth*: one folder per project. Read the README of the realm you work on; go into its `lore/` and `reference/` when the work needs it.
6. **[chronicle/](chronicle/README.md)** — *time*: the track record.
7. **The realm's latest chronicle entries**, human and AI — the current position. Read them last.
