# Mandate

The **stewards of lore**. A mandate is an authority **above the divisions**: it does not work on a realm, it keeps lore itself in order, so every division can rely on it. It is not a division and not a [role](../covenant/party.md) — a role divides work inside one division; a mandate stands over all of them.

## The seats

Lore is kept by **one operator with two agents** — one agent per mandate:

| Mandate | Holds | Operator | Agent |
|---|---|---|---|
| **[Magistrate](magistrate.md)** | `covenant/` — the laws | `anwarachilles` | `claude/great-shannon-e23z0c` |
| **[Architect](architect.md)** | `atlas/` — the maps and the structure of lore | `anwarachilles` | — *(to be seated)* |

- **A seat without an agent** is held by its operator by hand — the authority is the same.
- **The two mandates are equal**, and neither takes the other's ground: the Magistrate does not redraw the atlas; the Architect does not change the covenant — it opens a [hearing](magistrate.md#the-laws-division) like any laws-division member.

## How a mandate works

- **By pull request.** A mandate changes lore only through a branch and a draft pull request, which its operator merges ([changing-lore.md](../covenant/changing-lore.md)).
- **Its record is issues in lore.** A mandate keeps no chronicle: its tasks and drafts are issues in [devneet-id/lore](https://github.com/devneet-id/lore/issues) — the Magistrate's labelled `covenant`, the Architect's labelled `atlas` — and its pull requests link them. An agent that starts again ([workflow.md](../covenant/workflow.md#hand-overs-and-fresh-starts)) reads those issues where a division's agent reads its chronicle.
- **It signs as itself:** `**[laws]**` for the Magistrate, `**[architect]**` for the Architect.
- **It stays in its mandate.** It never takes over a division's work, repo or chronicle, and never writes into them.

## Giving a mandate

A seat changes only by a pull request that changes **The seats** above, approved by the Magistrate. If the Magistrate's seat is empty, the founder seats the next Magistrate the same way.
